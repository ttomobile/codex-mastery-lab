# SagaForge Trial 070: 日課ループを「選択→編成→Round→報酬」で押せる形へ寄せる

前回までで、星紋遠征隊はホーム、スタイル、5人編成、クエスト、Round/BP/OD風の戦闘、10連結果の部品を持つようになった。ただしユーザー評価の「全然ロマサガRSとは程遠い」に対しては、まだ重要な不足が残っていた。

## 前回の何がロマサガRSから遠かったか

Trial 069 は日課順を固定したが、まだ次の点が弱かった。

- **日課ホームの判断が薄い**: 資源、プレゼント、ミッション、周回先、育成候補が「今日の1周」へまとまり切っていなかった。
- **スタイルカードを選ぶ手触りが弱い**: キャラではなくスタイル単位で、レアリティ、ロール、武器、属性、Style Lv、技Rank、ピースを見て採用する感覚がまだ前面に出ていなかった。
- **編成から戦闘・報酬へのつながりが弱い**: 5人陣形、予約BP、OD/連携、Round勝利、報酬/10連戻りが、1枚の操作盤として押せる状態ではなかった。

## 今回どの差分を潰したか

Trial 070 では、プレイアブル版のホームに **「日課ループを“選択→編成→Round→報酬”で押せる化」** パネルを追加した。

追加した主な操作は次の6つ。

| 操作 | 画面上の役割 | 潰した差分 |
|---|---|---|
| 日課開始 | 贈り物、素材、育成対象、周回予約、BP/OD予約を一括更新 | ホームが説明で止まる問題 |
| スタイル選択 | スタイルLv、技Rank、ピース、武器/属性を見に行く | キャラ単位ではなくスタイル単位に寄せる |
| 5人陣形 | 陣形を切り替え、前衛/中衛/後衛と行動順を更新 | 5人編成の手触り不足 |
| 周回先 | 消費スタミナ、推奨戦力、弱点、報酬を更新 | クエスト選択の薄さ |
| Round勝利 | BP/OD連携を勝利報酬へ接続 | 戦闘がHP変化だけに見える問題 |
| 10連反映 | 重複ピースと交換Ptをスタイルカードへ戻す | ガチャ結果が育成へ戻らない問題 |

![Trial 070 ホーム操作盤](assets/2026-07-09-character-collection-rpg-trial-070-home.png)

日課開始を押すと、クエスト画面へ移動し、選択中クエスト、消費スタミナ、推奨戦力、弱点、周回予約が確認できる。

![Trial 070 クエスト遷移](assets/2026-07-09-character-collection-rpg-trial-070-quest.png)

Round勝利を押すと、戦闘画面で勝利報酬が更新され、能力値・技Rank・ピース・記憶片・技書を、育成/交換/再戦/10連へ戻せる状態にした。

![Trial 070 戦闘結果](assets/2026-07-09-character-collection-rpg-trial-070-battle-result.png)

## まだ遠い点

まだ「ロマサガRS的な期待」に対して足りない点はある。

- 戦闘中の連携演出はまだカードとログ中心で、カットインやテンポの気持ちよさは弱い。
- スタイル強化は数値更新中心で、限界突破・技Rank・覚醒の選択圧はまだ浅い。
- クエスト周回の複数Round、敵行動、状態異常、AUTO周回リザルトの実感はまだ簡易版。
- 召喚演出は段階表示があるが、結果から編成/育成へ戻る導線をもっと短くできる。

## 次に潰す差分

次回は、以下を優先する。

1. **戦闘テンポの演出密度**: 5人行動順、弱点、BP消費、OD上昇、連携名、ダメージポップを1ターン内でより分かりやすくする。
2. **スタイル育成の選択圧**: ピース不足、突破可能、技Rank上昇、継承技候補を、育成画面だけでなくホーム/編成に強く戻す。
3. **勝利後30秒ループの短縮**: 勝利→報酬→突破/交換/再戦/10連を、さらに迷わず押せる導線にする。

## AIDD-Spec / Control Plane への学び

今回の差分は、単なる見た目追加ではなく「ユーザーが期待する体験パターンとの差分」を1サイクルで潰すための小さな検証だった。AIDD Control Plane 的には、次のルールが効いた。

- ユーザー評価を先に受け止め、不足を明文化する。
- 記事より先に、触れるプレイアブルURLを改善する。
- 実在IP・公式素材・商標・公式文言は使わず、体験パターンだけを抽象化する。
- 1サイクルごとに、ホーム/スタイル/編成/クエスト/戦闘/報酬のどこが遠いかを狭く潰す。

プレイアブル版は `playables/sagaforge-app/` から `preview/sagaforge-app/` へコピーされる。公開URLはレポート本文で別途提示する。
