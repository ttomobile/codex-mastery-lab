# SagaForge Trial 061：スタイル選択と5人編成の悩ましさをホームに足す

## 前回の何がロマサガRS的な期待から遠かったか

ユーザー評価の「全然ロマサガRSとは程遠い」を、今回も正面から受け止めた。Trial 060では、ホームからスタイル、5人編成、イベント周回、Round/BP/OD戦闘、10連結果までを一本化した。

ただし、まだ次の不足が残っていた。

- 画面構造は近づいたが、「どの同一キャラ別スタイルを使うか」という悩ましさが薄い。
- 5人編成は表示できるが、敵弱点・前衛/中衛/後衛・陣形補正・継承技を見比べて入れ替える判断がまだ弱い。
- 10連結果はカード化したが、重複ピースや交換Ptが「編成に入れるか、育成に戻るか」の判断へ直結しきっていない。

今回も、アプリ本体では実在IP名・公式素材・商標・ロゴ・キャラ・公式文言・公式確率は使っていない。記事ではユーザー評価の文脈として、ロマサガRS的な期待差分という言葉を使っている。

## 今回どの差分を潰したか

Trial 061では、プレイアブル版ホームに **スタイル選択と編成判断ボード** を追加した。

- 選択クエストの弱点、推奨戦力、消費スタミナをカード化。
- 同一キャラの別スタイル候補を、レアリティ、ロール、武器、属性、継承技つきで表示。
- 推奨入替候補を、前衛/中衛/後衛、陣形補正、弱点一致、適性スコアとして見せる。
- 育成判断を、Style Lv、限界突破、技Rank、ピース数で表示。
- 5人予約を、BPコスト、OD/連携、Round情報として表示。
- 10連後の戻り先を、重複ピース、交換Pt、編成入りの判断へつなげた。

ボタンとしては、次の4つを追加した。

- `弱点適性で入替`: 推奨入替候補を編成枠へ反映。
- `育成候補で入替`: 育成対象スタイルに合わせて周回先を変更。
- `連携優先で予約`: OD/連携寄りの周回デッキへ切り替え、戦闘画面へ移動。
- `召喚結果から反映`: 10連結果を更新し、突破候補スタイルへ戻る。

## まだ遠い点

- まだカード中心で、実際のスマホRPGで感じる派手な連携演出やカットイン密度は足りない。
- 同一キャラ別スタイルの差は表示したが、長期育成で「このスタイルを今使う理由」がもっと必要。
- 入替は1クリックで反映できるが、敵ごとの耐性、状態異常、Roundごとの敵構成まで踏み込めていない。
- 10連結果から編成入り・突破・交換Ptショップまでの導線は、まだホームの要約中心で、演出段階としては薄い。

## 次に潰す差分

次回は **戦闘テンポと連携演出の弱さ** を優先して潰す。

- Roundごとの敵構成、弱点、技選択、BP回復、OD発動条件をもっと見える化する。
- 5人行動リールに、技名、ヒット数、追撃、連携名、勝利報酬を段階表示する。
- 勝利後に、スタイル能力上昇、技Rank、ピース、ミッション達成、再戦/育成/召喚戻りをより気持ちよくつなぐ。

## AIDD-Spec / Control Plane への学び

AIに「キャラ収集RPGっぽく」とだけ頼むと、キャラカードとバトル画面は出ても、プレイヤーが期待する判断の鎖が抜けやすい。

今回の差分から、AI Task Packetには次の条件を入れるべきだと分かる。

- スタイルは、同一キャラ別スタイル、継承技、武器/属性/ロール差まで要求する。
- 編成は、5人表示だけでなく、敵弱点、陣形枠、推奨戦力、BP/OD予約と連動させる。
- 召喚結果は、重複ピース、限界突破、交換Pt、編成入り、周回先変更へ戻る導線まで検証対象にする。

これは AIDD Control Plane の「体験差分チェック」に追加するべき項目になる。
