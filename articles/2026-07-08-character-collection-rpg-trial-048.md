# SagaForge Trial 048: 戦術プリセットで「5人編成が戦闘テンポへつながる」手触りを足す

前回までで、ホーム、スタイル、5人編成、クエスト、OD風カットイン、勝利後ループはかなり増えた。けれど、ユーザーからの「まだ期待するキャラ収集RPG体験から遠い」という評価を考えると、単に画面やカードが多いだけでは足りない。

今回の不足整理はこうだ。

- 個別の要素はあるが、「このクエストではどの5人行動を選ぶのか」が毎回手作業に見えた。
- 5人編成、スタイル、BP、OD、弱点、周回報酬が別々の情報として並び、スマホRPGらしい作戦選択のまとまりが弱かった。
- 戦闘テンポは改善してきたが、プレイヤーがワンタップで「周回安定」「OD狙い」「耐久立て直し」を切り替える感覚がまだ薄かった。

## 今回潰した差分

Trial 048では、プレイアブル版に **戦術プリセット** を追加した。

追加したプリセットは3つ。

| プリセット | ねらい | 画面上の効果 |
|---|---|---|
| 周回安定 | 弱点2枚、補助、回復を混ぜてRoundを進める | ホーム/戦闘のプリセットカードから5人予約へ反映 |
| OD連携狙い | 補助と高OD技を先に置き、連携率を上げる | ODゲージを少し押し上げ、OD五連カットインへ誘導 |
| 耐久立て直し | 通常攻撃でBPを戻し、補助/回復/継承で崩れを戻す | 隊列HPを少し戻し、再度周回安定へ戻れる |

これにより、スタイル単位の5人編成が、ただのカード表示ではなく、戦闘中の行動予約・BP消費・連携率・OD導線へつながるようになった。

## プレイアブルで確認できること

公開プレイアブルでは、次の順で触れる。

1. ホームの「Trial 048: 戦術プリセット / 差分つぶし」を見る。
2. 「OD連携狙い」または「耐久立て直し」を押す。
3. 戦闘画面へ移動し、5人連携予約の行動列、予約BP、連携率が変わったことを確認する。
4. 「予約ターン実行」または「OD連携発動」を押し、テンポリールとログを確認する。

前回までは「機能が増えた」状態だったが、今回は「クエストに向けて5人分の戦術を選ぶ」入口を足した。これは、ユーザーが期待しているキャラ収集・スタイル育成・ターン制バトルのまとまりに少し近づけるための修正である。

## AIDD Control Planeとしての学び

今回のAIDD的な学びは、欠点を「画面が足りない」ではなく、**情報が行動へ変換されているか** として扱うことだ。

今回の逆算は次の通り。

```text
観測された不足
  -> 5人編成・BP・OD・弱点が別々に見える
理想状態
  -> プレイヤーが目的別プリセットを選ぶと5人行動予約へ反映される
修正指示
  -> ホームと戦闘に戦術プリセットを追加し、予約BP/OD/連携率を更新する
必要な上流情報
  -> 戦術プリセット契約、スタイル役割、クエスト弱点、戦闘テンポ契約
検証
  -> Playwrightでホーム/戦闘/プリセット反映/公開URLを確認
```

## まだ遠い点

まだ本格的なキャラ収集RPG体験としては足りない点がある。

- スタイルごとの固有アビリティ差は見えるが、長期育成の差分はまだ浅い。
- イベント周回の報酬交換、ミッション達成、スタイル突破の気持ちよさは、まだ静的カード寄り。
- 戦闘演出は抽象カード中心で、スマホRPGらしい演出密度や音/間の気持ちよさは不足している。
- ガチャ結果から編成・育成へ戻る導線はあるが、所持/未所持/重複/ピース変換の図鑑的な満足感はさらに改善余地がある。

## 次に潰す差分

次回は、今回の戦術プリセットを土台にして、次の差分を潰したい。

- スタイル別の「周回で伸ばしたい能力」「技Rank」「突破候補」を、ホームとリザルトでさらに強く出す。
- クエスト選択時に、推奨戦力だけでなく、弱点・報酬・育成対象・戦術プリセットを1つの出撃確認にまとめる。
- 召喚結果の10連カードを、所持図鑑、ピース変換、突破可能、編成おすすめへより強く接続する。
