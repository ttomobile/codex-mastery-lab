# SagaForge Trial 063: ホームから1分でスタイル育成・5人編成・クエスト・戦闘テンポへ入る

公開プレイアブル: [星紋遠征隊 SagaForge](../sagaforge-app/index.html)

## 前回の何がロマサガRS的な期待から遠かったか

前回 Trial 062 では、Round、BP、OD/連携、勝利報酬を5ステップのリールにまとめ、戦闘だけを見ると「ボタンでHPが少し変わる」段階からは前進した。

ただし、ユーザーが期待するキャラ収集スマホRPGの体験としては、まだ次の差分が残っていた。

- ホーム、スタイル、編成、クエスト、召喚が個別カードとして増え続け、起動直後に何を押せばよいかが散っていた。
- スタイルカード、5人編成、陣形、クエスト、Round/BP/OD戦闘、勝利後報酬が「1本の周回ループ」として読みにくかった。
- 下部ナビはあったが、ホーム内に高密度なスマホRPG風のショートカットが不足していた。

## 今回どの差分を潰したか

Trial 063 では、記事より先に `playables/sagaforge-app/index.html` を改善した。アプリ本体には実在IP名、公式素材、公式文言、ロゴ、公式確率は入れていない。

主な変更は次のとおり。

1. **ホーム内ミニナビを追加**  
   `スタイル / 5人編成 / クエスト / 戦闘 / 10連` をホーム上部の Trial 063 パネルから直接触れるようにした。

2. **1分周回ボードを追加**  
   ホーム密度、スタイルカード、5人編成/陣形、クエスト→戦闘、勝利後導線、10連結果を6枚のカードで表示した。

3. **5人編成の見え方をホームへ戻した**  
   前衛2・中衛2・後衛1、各スタイルのレアリティ/武器/属性、予約技とBPをホーム内に出した。

4. **操作ボタンを周回ループ化した**  
   `1分周回を開始`、`育成候補へ`、`陣形入替`、`10連→ピース` を追加し、ホームから育成・編成・クエスト・召喚へ戻れるようにした。

## まだ遠い点

今回で「ホームから1分で触れる構造」は前進したが、まだ本格的なキャラ収集RPG体験には遠い。

- スタイル育成の深さはまだ浅く、能力値成長、技Rank、継承、ピース突破の悩ましさが軽い。
- クエスト選択はあるが、周回難度・属性相性・ミッション達成条件の駆け引きがまだ薄い。
- 戦闘はテンポを圧縮したが、敵複数体の行動、状態異常、被弾予測、勝利演出の密度が不足している。
- 10連結果はスタイルカード化しているが、演出段階と重複時ピース変換の気持ちよさはまだ弱い。

## 次に潰す差分

次回は、Trial 063で作った1分ループを土台にして、次の1〜3点を重点的に潰す。

- スタイル詳細画面で、同一キャラ別スタイル、継承技、突破、育成ルートをもっと悩めるようにする。
- クエスト選択からバトルへ入ったあと、Roundごとの敵配置・弱点・BP温存/OD解放の判断を強める。
- 10連結果から、重複ピース、突破候補、編成採用、交換Pt到達までの戻り先をより気持ちよくする。
