# Product Brief

## 対象体験

`SagaForge Trial 001`は、キャラクター収集、編成、遠征選択、ターン制戦闘、勝敗、報酬、幻晶結果、育成を短いスマホ操作で確認するWebプロトタイプです。

## 差別化したゴール

- 既存IP名、ロゴ、公式文言、公式素材を使わず、操作パターンだけを抽象化する。
- mock serviceの状態をE2Eから切り替え、成功と失敗のUI反映を証明する。
- 見た目だけでなく、編成妥当性、戦闘状態、幻晶結果、ready判定をunit testで検証する。

## 非ゴール

- 実課金、実ガチャ確率、実アカウント連携は作らない。
- ネイティブアプリやUnity製ゲームは作らない。
- 実在サービスの商標、ロゴ、キャラクター、画像、コピー、料率は使わない。

## 主要ユーザーフロー

1. ホームで所持隊員、準備度、幻晶状態を見る。
2. 名簿で隊員の役割と育成状態を確認する。
3. 編成で出撃条件を確認する。
4. 遠征を選び、戦闘画面で勝敗とログを見る。
5. 幻晶結果で独自ラベルの獲得演出を見る。
6. 育成画面で強化対象を確認する。
7. 状態画面でmock scenarioを切り替え、失敗表示を確認する。
